# ⚔️ The Odin Project – Foundations

This repository contains my ongoing projects and exercises from [The Odin Project Foundation Course](https://www.theodinproject.com/paths/foundations/courses/foundations).

The Foundations course covers the core building blocks of web development, including Git, HTML, CSS, and JavaScript. Each folder in this repository corresponds to a lesson or project from the curriculum.

---

## 📚 What I Learned

### 🔹 Git & GitHub
- Repository setup and version control
- Branching and commits
- Pushing projects to GitHub
- Writing clean README files

### 🔹 HTML
- Semantic HTML structure
- Forms and input elements
- Lists, links, and images
- Proper document structure

### 🔹 CSS
- The Box Model
- Flexbox layout
- Basic responsive design
- Styling with classes and IDs

### 🔹 JavaScript
- Variables and data types
- Functions and scope
- Conditionals and loops
- DOM manipulation
- Event handling
